# Token 说明

> 状态: v1.1 | 创建: 2026-11-18 | 最后更新: 2026-11-18 | 关联: ../themes/flockbook.json, tokens.json

源文件是 `../themes/flockbook.json`；本表解释每个 token 的**语义**，避免直接拿颜色名当含义用。

| Token | 语义 | 使用位置 | 禁止用途 |
|---|---|---|---|
| `canvas` | 主画布 | 内容区、终端背景 | 侧栏、卡片 |
| `chrome` | 窗体框架 | 侧栏、顶栏（若有） | 主内容背景 |
| `raised` | 浮起表面 | 卡片、输入框、弹层 | 页面背景 |
| `hover` | 悬停反馈 | 列表项 hover | 静态元素 |
| `selected` | 选中态 | 当前会话/任务 | 悬停 |
| `border` | 边界 | 1px 分隔线、焦点框 | 大面积填充 |
| `muted` | 次要信息 | 时间、元数据 | 主标题 |
| `dim` | 弱化信息 | 占位、禁用 | 正文 |
| `accent` | 强调 | 焦点、当前选择、品牌 | 大面积背景 |
| `working` | 运行中 | 状态点/文字 | 装饰 |
| `done` | 完成 | 状态点/文字 | 装饰 |
| `blocked` | 受阻 | 状态点/文字 | 装饰 |

## 状态色约定

`working`、`done`、`blocked` 都落在同一灰阶体系内（`#9a9a9a` / `#ededed` / `#ededed`），这是刻意设计：

- 状态由**位置、文案、图标**表达，颜色不承担区分职责；
- 多 agent 并行时避免彩色噪音；
- 灰阶并不意味着“不可区分”：状态点与文字标签始终同时出现。

## ANSI 调色板

`themes/flockbook.json` 的 `ansi` 数组提供 16 色，全部为灰阶（不同亮度）。
Space 颜色、终端输出因此保持单色；强调仅通过亮度与字重实现。
