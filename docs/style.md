# Flockbook 风格细则

> 状态: v1.0 | 创建: 2026-11-18 | 最后更新: 2026-11-18 | 关联: README.md, tokens/tokens.json

## 1. 亮度层级（唯一的结构语言）

| 层级 | Token | 用法 |
|---|---|---|
| L0 | `canvas` | 主内容区 |
| L1 | `chrome` | 侧栏、窗体框架 |
| L2 | `raised` | 卡片、输入框、弹层 |
| L3 | `hover` | 指针悬停 |
| L4 | `selected` | 当前选中项 |

规则：

- 相邻层级亮度差保持可辨但克制（深色约 +8~+10 亮度值）。
- 不用投影表达层级；需要边界时只用 1px `border`。
- 反例：同屏出现两种以上强调色；用颜色区分非语义内容；给静态元素加动画。

## 2. 状态语义

| 状态 | 表达优先级 |
|---|---|
| working | 点位/文案优先；`working` 为灰阶 |
| done | 文字或对勾优先；`done` 为灰阶 |
| blocked | 阻塞原因文案优先；`blocked` 为灰阶 |

三个状态同色是**有意为之**：多 agent 并行时，颜色不承担状态区分，避免视觉噪音；状态靠位置、文案与图标。

## 3. 排版

- 唯一字体：Maple Mono NF CN；UI 与终端同族，等宽保证对齐。
- 连字关闭：避免 `->`、`!=` 等符号形变干扰代码阅读。
- 层级靠字重与 `foreground/muted/dim`，不引入第二种字体。
- 最小字号以可读性为准；界面缩放保持整数倍。

## 4. 布局

- 无标题栏；窗口控件偏移 18/22。
- 侧栏 250px（220–320 可拖拽），1px 分隔线。
- 侧栏条目 = 名称 + 状态点 + 标签；悬停显示操作，不常驻按钮。
- 拖拽排序：让位 160ms，落位 100ms；取消用 Esc，不做弹窗确认。

## 5. 图标与色彩

- 图标单色、不透明着色（`tint: false`），底色 `#1c1d21`。
- Space 颜色使用 ANSI 索引（如 `ansi3/4/6`），跟随主题而非写死 hex。
- 强调只有一个来源（`accent`）；其余全部来自灰阶。

## 6. 反例清单

- 用红/绿同时表达“运行中/失败”以外的含义。
- 深色背景上用纯黑阴影做层级。
- 引入第二套字体或开启连字。
- 常驻彩色徽标、渐变、发光边框。
- 装饰性动画（呼吸、漂移、闪烁）。

## 7. 变更流程

1. 改 `themes/*.json`（源文件）。
2. 同步 `tokens/tokens.json` 与 README 表格。
3. 用 `preview/index.html` 检查渲染效果。
4. 重新生成 `screenshots/` 后提交。
