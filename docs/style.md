# Herdr 当前界面风格细则

> 状态: v2.0 | 创建: 2026-11-18 | 最后更新: 2026-11-18 | 关联: README.md, layout/agents-order.json

风格定义：**浅色中性外壳 + 单色等宽字体 + 少量功能色**。结构靠 1px 分隔线与圆角面板表达，颜色只用于身份与状态。

## 1. 外壳

- 无标题栏；窗口控件偏移 12/16。
- 侧栏展开 268px（`resizable: false`，不可拖宽）；折叠 44px，由侧栏按钮切换；底色 `chrome`；品牌行 46px。
- 标签栏 42px；状态栏 28px；右侧面板 368px（默认隐藏，280–900）。
- 主区背景 `canvas`；分屏 gap 8、圆角 10、1px border、面板头 30px。
- 终端内边距 14/12；分隔线统一 1px。

## 2. 侧栏

两个分区，标题均为 `muted` 小字：

**Spaces**

- 每行：彩色字母徽标 + Space 名 +（可选）分支名（`dim`，斜体）。
- 当前行底色 `selected`；悬停用更浅一级的灰。
- 徽标颜色属于“身份色”，同一个 Space 保持稳定，不随状态变化。

**Agents / 待办**

- 每行：拖拽手柄（⋮⋮）+ 任务名 + 右侧时间（`dim`）+ 状态环（○）。
- 任务名为主文字色；子任务缩进并用 L 形引导线。
- 状态环：默认灰色空心；运行中显示蓝色半环/圆点；完成用对勾；阻塞用琥珀色。
- 分区切换（Agents / 待办）用文字标签，选中项加下划线或加粗，不使用胶囊底色。

## 3. 排版

- 唯一字体：Maple Mono NF CN（UI 与终端一致），连字关闭。
- 任务名约 13–14px；元数据 11–12px；分区标题 11px + letter-spacing。
- 层级靠字重与 `text / muted / dim`，不引入第二套字体。
- 分支名用 `dim` + 斜体，与任务名形成轻对比。

## 4. 颜色角色

| 角色 | 色值 | 规则 |
|---|---|---|
| 外壳 | `#f1f1ee` | 侧栏、标签栏；不用纯白 |
| 画布 | `#ffffff` | 终端与内容区 |
| 选中 | `#e0e0dd` | 当前 Space / 任务行 |
| 边界 | `#e3e3e3` | 1px 线；不加重 |
| 主文字 | `#1b1b1e` | 标题、任务名 |
| 次要 | `#69696b` | 分区标题、图标 |
| 弱化 | `#969698` | 时间、分支 |
| 强调 | `#668ce8` | 激活指示、搜索/品牌图标 |
| 身份/状态 | 青 `#52a69a`、橙 `#d68659`、红 `#ec6a5e`、黄 `#f4bf4f`、绿 `#61c554` | Space 徽标、状态环 |

规则：同一屏内身份色不超过 Space 徽标所需数量；强调蓝只用于“当前激活”；状态色只出现在环/点上。

## 5. 面板与标签

- 标签为文字/图标组合，当前项用下划线或高亮文字，不使用大面积填充。
- 面板统一 1px border + 10px 圆角；焦点靠边框色变化，不发光。
- 图标单色线条风；与文字同色或 `muted`。

## 6. 反例

- 深色阴影、渐变、发光边框。
- 第二套字体或开启连字。
- 用身份色大面积铺底。
- 状态同时用颜色和动画表达（选一种）。
- 常驻彩色徽章堆叠导致侧栏噪音。
